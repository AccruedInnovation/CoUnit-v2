# Archived private 2.0.1.0 implementation objects

These exact exports were unreferenced by the active CoUnit closure at the start
of the 2.1 upgrade. They include the obsolete assertion-history trackers, unsafe
raw conversion helpers and former file/XML writers. They are retained for history
and are excluded from candidate packages. Use the current shared assertion engine,
streaming publishers and public catalog/control API. Do not import this tree into
a current consumer application.
