2. RF-008 path byte-capacity counterexample
R2 rule: reporting-contract.md §6 requires LEN(finalPath) <= 244 before appending '.counit.tmp' / '.counit.bak'.
CODESYS contract facts used by review: STRING(255) capacity is byte-based; Standard LEN reports characters.
Analytical UTF-8 fixture:
  P = 122 repetitions of U+00E9: character count 122, UTF-8 bytes 244, with 11-byte suffix = 255 bytes -> boundary fits.
  P = 123 repetitions of U+00E9: character count 123, UTF-8 bytes 246, with 11-byte suffix = 257 bytes -> does not fit.
R2 LEN rule admits the second case because 123 <= 244.
Consequence: a conforming R2 worker may overflow/truncate a companion path or fail to prove distinct path identities before file effects.
